# 🤖 AI Tools Hub

> Discover the best AI tools for Coding, Writing, Design, Research, Video, Productivity, and Business — all in one place.

AI Tools Hub is a modern, responsive, and easy-to-use AI tools directory built with **HTML, CSS, JavaScript, JSON, and Tailwind CSS**.

The website allows users to explore different AI tools, view their descriptions, see their icons, and visit the official tool website.

---

## 🌟 Project Overview

AI Tools Hub is designed to make discovering AI tools easier.

Instead of searching across multiple websites, users can browse AI tools by category from a single clean interface.

The project uses a JSON-based data structure, which means new AI tools can be added easily without changing the main HTML layout.
